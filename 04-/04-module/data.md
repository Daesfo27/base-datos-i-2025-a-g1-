Refinar datos con la herramienta de refinería de datos

==========================================================


Acabas de realizar una serie de pasos en IBM Watson Studio con la herramienta de refinación de datos para investigar la hipótesis de que reclamaciones de seguro superiores a $10,000 podrían ser fraudulentas.

Lo que hice:

- Refinaste el conjunto de datos añadiendo una nueva columna que identifica reclamaciones superiores a $10K.
- Investigaste la relación entre montos de reclamación y fraude potencial.
- Te preparaste para el siguiente paso: crear una visualización inicial para analizar más a fondo los datos.
