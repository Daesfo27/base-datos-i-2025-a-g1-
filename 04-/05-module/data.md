Introducción

Aca tendremos practicas para herramienta de refinacion de datos


Objetivos de aprendizaje

Después de completar este módulo, debería ser capaz de:

Crear una visualización de datos
Conclusión de la información a partir de una visualización de datos

=============================================================


Has utilizado IBM Watson Studio y la herramienta de refinación de datos para preparar, limpiar y refinar un conjunto de datos de reclamaciones de seguros de automóviles con el objetivo de predecir fraudes.  

Ahora, estás en la fase de visualización de datos, donde explorarás patrones y relaciones entre variables para obtener conclusiones. Las visualizaciones te ayudarán a identificar conexiones que podrían indicar comportamientos fraudulentos en las reclamaciones.  

Este proceso te permitirá analizar mejor las hipótesis planteadas, como la relación entre el monto de la reclamación y la probabilidad de fraude.
