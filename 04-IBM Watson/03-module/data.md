Limpieza de datos con la herramienta de refinería de datos

==========================================================

 Comprender y limpiar los datos
 tenemos unos pasos a realizar

 - Revisión de columnas: Usaste la pestaña Datos para analizar y seleccionar las columnas relevantes, como la causa del incidente y datos de fecha/hora.

 - Eliminación de datos innecesarios: Eliminaste columnas sin valor predictivo, como información personal, números de identificación y aquellas con datos faltantes.

 - Análisis de estadísticas descriptivas: Usaste la pestaña Perfil para revisar métricas como la desviación estándar, lo que ayudó a identificar datos útiles para el modelo.

 - Corrección de tipos de datos: Ajustaste el tipo de datos en ciertas columnas para garantizar cálculos precisos y mejorar la calidad del conjunto de datos.


 estos pasos nos ayudaran hacer mas eficientes
