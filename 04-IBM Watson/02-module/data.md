
Introducción

Aprenderemos sobre el escenario de el proyecto de ciencia de datos,esto tambien nos ayudara a practicar y tener en cuenta este proyecto de IBM Watson Studio


Objetivos de aprendizaje

Después de completar este módulo, debería ser capaz de:

Configurar un nuevo proyecto en IBM Watson Studio
Importar un conjunto de datos

======================================================

Su proyecto de ciencia de datos:

Eres un científico de datos en una compañía de seguros de automóviles, trabajando en un proyecto para predecir fraudes en reclamaciones y reducir pérdidas millonarias. La digitalización ha agilizado las transacciones, pero ha dificultado la detección del fraude.  

Usando IBM Watson Studio y la herramienta de refinación de datos, tu tarea es:  

1. Configurar el servicio y un nuevo proyecto.  
2. Importar y limpiar un conjunto de datos ficticio de 975 registros y 38 columnas.  
3. Refinar y visualizar los datos para obtener información.  

El seguro de autos se basa en pólizas de seis meses, con costos determinados por factores como el tipo de auto, historial del conductor y edad. Conductores con buen historial pueden acceder a primas más bajas.
