Visualizacion de los Datos 

-La visualización de datos es fundamental para poderse comunicar y utilizar información compleja de manera clara y comprensible. Sirve tanto para explorar e interpretar ciertos datos durante el análisis el cual estamos recolectando a medida de ver estos mismos, identificando patrones y tendencias, como para presentar resultados y facilitar la toma de decisiones. A través de tablas, gráficos y mapas, se pueden transmitir conocimientos de forma más efectiva, ya que una imagen puede simplificar y dar claridad a cuestiones complicadas. "por eso se dice que una imagen vale mas que mil palabras".
