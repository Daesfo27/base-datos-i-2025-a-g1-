

Introducción

Aprenderemos sobre el papel de un analistas de datos,y un ingeniero de datos y como se colobora en un proyecto

Objetivos de
aprendizaje

Después de completar este módulo, debería ser capaz de:

Comparar las funciones y características de un analista de datos, un científico de datos y un ingeniero de datos


===============================================================


El equipo del proyecto de ciencia de datos


El equipo de ciencia de datos colabora para analizar y utilizar datos en la toma de decisiones empresariales:

Joseph (Analista de Datos): Limpia, organiza y visualiza datos.
Zhanna (Científica de Datos): Crea hipótesis, entrena modelos y experimenta con técnicas.
Ronnie (Ingeniero de Datos): Administra bases de datos y despliega modelos en producción.
Trabajan juntos desde la limpieza de datos hasta la implementación y presentación de resultados.
