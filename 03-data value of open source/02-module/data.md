Excel

Microsoft Excel es una herramienta ampliamente utilizada para el análisis de datos. Permite introducir, manipular y limpiar datos, aplicar fórmulas y tablas dinámicas y crear gráficos como circulares, de barras y de líneas para visualizar tendencias. También ofrece plantillas y recomendaciones para optimizar la presentación de datos.

========================================================

Hoja de calculo

Hojas de cálculo de Google es una herramienta gratuita para "introducir, analizar y visualizar datos". Ofrece funciones similares a Microsoft Excel, permitiendo crear gráficos y tomar decisiones basadas en datos.

Lenguaje de consulta estructurado
¿Qué es SQL?

SQL (Structured Query Language) es un lenguaje estándar para interactuar con bases de datos relacionales. Se usa para consultar, modificar y gestionar datos estructurados almacenados en tablas. Aunque no es un lenguaje de programación, permite realizar operaciones esenciales como seleccionar, insertar, actualizar y eliminar datos.

Con SQL, puedes:

Consultar y recuperar información de una base de datos.
 Agregar, modificar o eliminar registros.
Crear y gestionar bases de datos, tablas y vistas.
- Definir permisos y seguridad sobre los datos.

===============================================================

Python

Python es un lenguaje de programación gratuito, de código abierto y fácil de usar, creado en 1991 por Guido van Rossum. Su diseño enfatiza la legibilidad del código y el uso de espacios en blanco.

Se usa en el desarrollo web y en ciencia de datos, gracias a su capacidad para manejar grandes volúmenes de datos, realizar cálculos complejos y conectarse a bases de datos. Con librerías como Pandas, permite analizar y visualizar datos de manera eficiente.

Python tiene una gran comunidad y ofrece una amplia variedad de paquetes de código abierto. Es ideal tanto para principiantes como para programadores experimentados.

=======================================================

IBM Watson Studio 
"IBM Watson Studio"es un "entorno de desarrollo integrado (IDE)" diseñado para la "ciencia de datos y el aprendizaje automático". Permite a los desarrolladores trabajar con "herramientas de código abierto" en una"plataforma colaborativa y fácil de usar", incluso sin necesidad de programar.  

Incluye la "herramienta de refinería de datos", que permite "preparar, transformar y visualizar datos" mediante tablas y gráficos. Además, facilita la "automatización de tareas" para obtener resultados repetibles. Es ideal para analizar grandes volúmenes de datos y tomar decisiones basadas en ellos.

==========================================================

tableau:
es una herramienta de "visualización de datos e inteligencia empresarial" que permite analizar grandes volúmenes de datos de manera intuitiva, sin necesidad de programación.  

Con "Tableau", puedes "crear paneles interactivos, gráficos, mapas y tablas" para facilitar la toma de decisiones empresariales. Su interfaz visual y sus opciones de personalización hacen que sea una opción ideal para explorar datos de manera dinámica y efectiva.

==================================================================

Matplotlib

Matplotlib es una biblioteca de Python ampliamente utilizada para crear gráficos bidimensionales. Introducida en 2002 por John Hunter, es un proyecto de código abierto mantenido por la comunidad.

Con Matplotlib, puedes generar gráficos de dispersión, histogramas, gráficos de barras y más con solo unas pocas líneas de código. Además, permite crear visualizaciones estáticas, animadas e interactivas, y exportarlas en distintos formatos de archivo.
