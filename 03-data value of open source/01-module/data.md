=========================================================


¿Qué significa ser "abierto"?

El software de código abierto es aquel cuyo código fuente es público y puede ser utilizado, modificado y compartido por cualquier persona. Se basa en la colaboración de comunidades virtuales que contribuyen a su desarrollo mediante la revisión, mejora y distribución del código.

Aspectos clave del código abierto:
Uso: Puede ser utilizado libremente bajo la licencia correspondiente.
Ver: Cualquier persona puede revisar el código fuente.
Modificar: Se pueden hacer mejoras, corregir errores y proponer cambios.
Compartir: Se fomenta la contribución basada en un propósito común.


Terminología básica en código abierto:
Comunidad: Grupo de personas beneficiadas por el proyecto.
Colaborador: Persona que contribuye al proyecto.
Committer: Usuario con acceso para aprobar y actualizar el código fuente.
Código de conducta: Normas que garantizan un ambiente seguro y respetuoso.
Directrices de contribución: Reglas que explican cómo colaborar en el proyecto.

===============================================================


¿Por qué es valioso el software de código abierto?

Desde la perspectiva de un científico o ingeniero de datos, el software de código abierto es esencial para acceder a nuevas tecnologías, aprender y desarrollar habilidades. Las comunidades de código abierto ofrecen tutoría, oportunidades de networking y apoyo para el crecimiento profesional.

Para las empresas, el código abierto impulsa la innovación, reduce costos, facilita el desarrollo y mejora la seguridad y fiabilidad del software

========================================================

Git y GitHub

En GitHub, puedes trabajar con repositorios para gestionar y colaborar en proyectos de código. Algunas de sus principales funciones incluyen:

- Alojar tu propio proyecto de código abierto creando un repositorio y agregando archivos.

- Contribuir a proyectos existentes, accediendo a una copia del repositorio, realizando cambios y solicitando revisiones.

- Controlar versiones y mantener un historial de cambios en los archivos del proyecto.

- Colaborar con otros desarrolladores, revisando y fusionando cambios en el código.

- GitHub es una plataforma clave para la gestión de código en proyectos abiertos y privados.
