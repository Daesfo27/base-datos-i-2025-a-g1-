

 Introducción  

Este módulo explica cómo las empresas y las personas eligen herramientas de transformación de datos y lenguajes de programación.  

 Objetivos de aprendizaje  

- Conocer los factores que influyen en la selección de herramientas de transformación de datos en empresas.  
- Comprender qué aspectos considerar al elegir una herramienta de transformación de datos para aprender.

==========================================================


No hay una única herramienta adecuada para todos. Cada herramienta de transformación de datos tiene su propósito, ventajas y desventajas. Algunas se superponen en funcionalidad, pero la elección depende de las preferencias y necesidades. Por ejemplo, Python es popular por sus bibliotecas para análisis, mientras que Excel es ideal para crear gráficos fácilmente. La clave está en seleccionar la herramienta adecuada según el contexto y los objetivos.

========================================================

Cómo selecciona una empresa las herramientas?

Las empresas deben considerar varios factores al elegir herramientas de análisis y visualización de datos, como el tipo y volumen de datos, la necesidad de modelado, el nivel de interactividad de las visualizaciones, el perfil de los usuarios (científicos de datos, marketing, etc.) y el presupuesto. Seleccionar la herramienta adecuada en el momento oportuno es clave para optimizar el análisis y la toma de decisiones.

- Determinar el problema
- Recopilación y limpieza de datos
- Análisis de datos
- Validar el análisis y el modelo
- Visualización de datos

cada una con sus tecnicas y herramientas a tener en cuenta
